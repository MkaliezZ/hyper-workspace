# 同名项目与执行目标

映射 P02/P04/P07、C01/C02/C05、A02/A06/A10、E02/E04/E09/E10。项目名称是展示字段，业务目标始终使用项目 UUID、所属会话和明确版本。

导航中存在同名项目时，每个按钮显示目标及短编号；无障碍名称和悬浮提示保留完整 UUID。点击后读取该项目的消息、任务、成果和执行状态，不以最近项目或名称相似度代选。已有工作计划/任务说明仍通过问题、员工回答、确认及版本绑定处理执行歧义。

本次浏览器用例创建两个同名、不同目标的真实演示库项目：分别辨认并切换，核对消息隔离；发起明确标记的 fixture 执行，核对请求的准确 conversationId、成果的原始消息引用及另一项目没有该成果。修正前因无法辨认目标/编号失败，修正后 1 项通过（9.0 秒，无重试）。该用例不调用真实模型。

原生任务说明用例另外将已确认说明放入另一个同名项目，DSH/Hermes 均在调用模型前拒绝，原项目随后正常执行，另一项目没有成果。1 项原生联合用例通过（42.3 秒），使用真实 SDK 与受控协议模型；不能冒充真实供应商理解质量。类型检查和构建通过，完整新提交 CI 单独记录。

没有新增迁移、引擎参数或依赖；回退仅涉及展示与回归测试。项目 UUID 绑定、服务端范围校验与澄清机制保持有效。
