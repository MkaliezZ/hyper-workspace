# 长文分块与多资料问答

2026-10-31 本地开发批次；P02/P04/P05/P07/P08，C02/C04/C05/C07，A04/A06/A07/A08/A10，E02/E04/E05/E07/E09/E10 子集。未宣称公司检索质量或正式业务验收通过。

受控文档提取上限由 18000 增至 180000 UTF-16 字符，超出明确拒绝；PDF 50 页、文件 8 MiB 与原有解压/资源限制不变。文本原件的 64 KiB 读取限制不变。索引按最多 2000 字符、200 字符重叠分块，保留原文起止位置、源版本、独立模型空间与维度；不能把向量当原件或当前业务状态。

每次索引显式选择 1–20 个可读资产，最多每请求 32 个分块；每批发送模型前重新核验当前权限、来源版本和模型连接，并使用原有供应商请求/费用账本。单资产全部分块就绪后原子保存。不同 profile/endpoint/model 的索引不混合；查询先在获准资产范围内召回，返回前再次核验当前版本。内容、权限范围、来源、版本变化或删除会清除分块和旧向量。

知识库可选择 1–10 份确切版本资料，填写问题并确认费用后发起 `query_knowledge`。支持关键词或独立 embedding 连接语义检索，没有可用向量时明确使用词法片段。最多 16000 字符/12 个片段，先保证每份已选资料至少一个候选片段，再补充相关片段；无匹配、部分覆盖和不可用索引明确标记。词法匹配采用英文词/数字和汉字双字片段，没有专门中文召回率结论。

DSH/Hermes 的共同工具 `knowledge.answer` 只可提交回答正文，引用必须来自本次服务端提供的确切位置。回答保存在发起人的 Run 中，不写项目消息。来源更新/删除会清除相关问题、回答与运行摘要；撤权拒绝读取。模型期间来源变化、编造引用、跨员工/项目访问不能保存或读取回答。查看引用时后端再次鉴权和核验版本；单次最多 4000 字符，拒绝不完整 Unicode 字符边界。私人运行目录在结束/恢复对账时清理。

人工可调用 `POST /knowledge/context` 取同范围片段；`POST /knowledge/citation` 读取确切位置。人工查找与 AI 使用同一来源/权限服务。单文件 AI 阅读超过 18000 字符时也使用受控片段，不把整份长文默认交给模型；短文保持原路径。

迁移 `027_knowledge_chunks.sql`、`028_knowledge_queries.sql`、`029_knowledge_source_deletion.sql` 分别建立可重建分块、私有问答与源删除清理。升级需先迁移再更新 API/Worker/Web，不必更新模型密钥。旧 `text-v1` 索引有兼容读取；重建为 `text-chunks-v1` 会消耗所选 embedding 额度。回退先停止问答/索引任务并对账，保留业务 Run 历史和源清理触发器，不直接退回会暴露过期派生答案的旧读取路径。

本地现有证据：2 个分块单元场景，8 个数据库/Worker/HTTP 模型协议场景，2 个桌面/手机问答场景与 8 个 Python 解析场景通过；含批量边界、独立向量空间、多资料、源变化/删除、假引用、私有回答、迟到引用清理。新增执行器前端可用性检查已复测。联合真实 DSH/Hermes 用例已通过（协议模型）；固定真实 Nextcloud、容器与真实供应商的整批回归仍待完成。
