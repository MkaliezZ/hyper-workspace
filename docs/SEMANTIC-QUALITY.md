# 真实中文 embedding 的产品检索检查

日期：2026-11-02（北京时间）。状态：**本机短中文合成样例通过；企业长文/RAG/完整检索与公司验收仍未完成**。映射 P02/P04/P07、C02/C07、A04/A06/A10、E02/E04/E07/E09 子集，不改冻结标准。

## 实际链路

使用可选本机 ONNX 模型，经正常 ModelProvider HTTP、用量记录、KnowledgeService 分块索引、实际 PostgreSQL/pgvector、当前源会话/个人权限和版本过滤。数据库为独立的本地 `_test` 库，模型连接只保存在本次合成工作区。两种身份和房间使用 HTTP 协议来源 fixture，非公司数据或真实 Nextcloud；模型权重与实际推理是真实的。

模型：[BAAI/bge-small-zh-v1.5](https://huggingface.co/BAAI/bge-small-zh-v1.5) 的 [Xenova ONNX 转换](https://huggingface.co/Xenova/bge-small-zh-v1.5)，512 维、q8、CLS pooling、归一化，固定转换提交和六份文件摘要。原模型卡标记 MIT；模型、依赖、大小/散列及运行命令见 [可选验收工具](../runtime/evaluations/README.md)。模型不成为产品新的必需基础服务。

输入是预先固定的 8 个办公主题和对应同义问法；执行前设定 Top1 ≥ 75%、Recall@3 = 100%，未根据结果修改语料、问法、期望对象或门槛。另放入更贴近查询措辞的私人和撤权资料，且确实为它们生成并保存了真实向量，检索仍须过滤。

## 权限和生命周期

- 另一员工的私人资料已有向量，但查询不返回它；拒绝给私人资料重新索引，未触发新模型请求。
- 另一个源房间失权后，其已有向量仍留在数据库；查询不返回该资料，重新索引也在供应商请求前被拒绝。
- 文本源版本改为 v2 而保留旧向量时，查询不返回旧向量；重新索引后只回读到当前 v2。
- 删除资料后查询不再返回它；从当前源房间移除员工后，原资料查询返回空。当前身份不能借模型相似度越过已失去的源权限。
- 一轮共 16 个本机 embedding HTTP 请求，全部 completed/reported；tokens 来自本地真实分词器的 attention mask，未编造供应商统计或发票。费用账本仍按未定价处理，不把本机推理声明为已核对的供应商零费用。0 次来源写入，临时凭据均禁用并清空。

## 可复查范围

先在临时协议服务完成首轮，再由仓库中的固定散列校验、可选模型服务和产品检查脚本完成第二轮；两轮均得到相同 7/8、8/8 和全部权限/生命周期结果。原报告、排名和限制保留在忽略的私有目录。依赖初次审计发现旧 sharp 的高危公告，覆盖至固定修复版本后官方 registry 审计为 0；不会把第一次因 registry 不支持审计而得到的空结果当成通过。

本模型只支持有限文本长度，验收服务显式拒绝超过 400 字符或 512 tokens 的输入，不静默截断。最初两轮只覆盖短文；后续容量配置与独立长文检查见下节。没有增加查询专用前缀或 reranker。尚不能推出 PDF/Office 长文、多跳问题、未知答案拒答、跨语言或公司术语质量合格；模型更换需重新评价。

这是一组真实向量检索质量与服务端权限证据，不是生成式问答质量、人类质量评分或公司采用记录。方法状态和拒绝请求结算修正的 `4f75829` 已在 [CI 41422563963](https://github.com/MkaliezZ/hyper-workspace/actions/runs/41422563963) 三项通过；本节后续容量/常驻实现的 CI 另行核对。
