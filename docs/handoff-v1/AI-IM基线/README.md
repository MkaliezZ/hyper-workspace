## 已固定的产品主张

人表达目标，AI 帮助推进；讨论有沉淀，行动有回执，成果能修改，经验能复用。整个过程清晰、克制，并保留人的掌控感。

三层关系：审美层提出价值与判断标准；功能层把它实现为可组合的工作能力；资产层提供事实、内容、关系、方法和成果。每项功能与每个数据源都必须能追溯到相关审美规则和工作场景。

## 已固定的技术路线

- 自有产品界面：React + TypeScript；首版以 Web 为主要完整产品界面。
- 自有产品后端：TypeScript + NestJS，先采用模块化单体，执行 Worker 分进程部署。
- 默认执行器：DSH；兼容执行器：Hermes。两者均经自有 EngineAdapter 接入，首阶段验证共同场景。
- 业务与资产目录：PostgreSQL；语义索引：pgvector；任务队列：pg-boss + 产品侧幂等、回执与对账。
- 通信服务：Nextcloud Talk；文件原件：Nextcloud Files/WebDAV；日历：Nextcloud Calendar/CalDAV，均经独立 Provider 接口接入。
- 企业知识与记忆：自有资产/知识服务，独立于 DSH、Hermes 和 Nextcloud 的 AI 模块。
- 模型管理：自有 ModelProvider 接口与服务端凭据管理，支持公司和个人 Key、自定义 endpoint、模型与用途配置。
- 首版运行环境：Docker Compose；执行 Worker 隔离运行，只挂载本任务允许的数据和工具。

暂缓进入首版核心：LangGraph、MindRoom、Context Chat、Nextcloud Assistant/Context Agent、LiteLLM、独立向量数据库、图数据库、Flowable、独立音视频服务、Kubernetes。暂缓不等于永久排除；新增必须对应明确的能力缺口和变更记录。
