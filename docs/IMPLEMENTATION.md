- React/Vite 的聊天、项目上下文、待办、成果修改、资料检索与模型配置界面。

- DSH 的真实运行时接线与 Hermes 的 stdio JSON-RPC 协议适配；实际验证范围见执行器增量。

## 模型与知识模块增量

- ModelService 按当前主体解析个人/工作区配置、用途和优先级；设置页可发起独立连接验证。支持的 HTTP 路径与验证含义见 MODELS-AND-KNOWLEDGE.md。
- 实际 pgvector 索引和语义召回，记录配置/维度/源版本，过滤私有、失效、删除与过期索引；不跨模型空间比较。
- 人工或 AI 修订成果时，同事务更新资料副本并废弃旧向量。
- 模型设置与知识页面拆为独立 React 组件；手机端保持可访问与无横向溢出。
- 本地 7 项单元、10 项数据库集成、4 项浏览器测试通过。向量供应商使用本地确定性 HTTP 测试服务，真实 embedding 质量未验证。

## 执行器接线增量

- Run 固定 model_profile_id，Worker 执行时重新鉴权并读取该配置。DSH 使用每次执行的独立 profile，关闭原生 shell/文件/目录工具；产品按 workflow 限制允许的动作。

- 通信关闭合并并发请求，等待实际进程退出，关闭后不能重新启动；不再把上游错误正文写入产品错误。

## Nextcloud 身份增量

- 独立 IdentityProvider 使用 Login Flow v2、当前用户和自身群组公开 API；后端维护稳定来源 UID/产品 UUID、按设备加密的应用密码及会话，前端只接收授权链接与完成状态。
- 群组准入与产品成员取交集；产品管理员首次映射由受控 UID 配置决定，Nextcloud admin 不自动映射管理员。重新登录不能绕过产品撤权。
- API、模型解析、Worker 开始、业务动作及最终发布前再次鉴权；Run 固定发起设备凭据引用。源服务故障阻止本次操作但不永久删权。产品撤权后旧来源恢复不自动恢复成员。
- 新增 9 项身份数据库测试，本地与 CI 共 23 项数据库测试通过；2 项登录 UI 协议测试检查重试与移动端取消。两个原生引擎的 3 项测试复测通过，模型仍为协议测试服务。
- 固定官方 Nextcloud 33.0.10 镜像摘要，并新增真实网页登录/应用密码撤销/群组撤销的独立 CI job。首次 run 40796637776 主 job 通过，来源浏览器授权入口定位超时；测试改为兼容 link/button 并补充页面诊断。提交 abf6a0c 的 [run 40797427984](https://github.com/MkaliezZ/hyper-workspace/actions/runs/40797427984) 两个 job 全通过，包含 3 项真实服务浏览器与撤权测试。没有连接真实公司数据。配置、来源绑定、失败窗口和迁移说明见 [NEXTCLOUD-IDENTITY.md](NEXTCLOUD-IDENTITY.md)。

## 来源项目与 AI 只读桥接增量

- 会话入口可创建唯一、不可改绑的受限项目；ProjectAccess 在产品身份/来源群组基础上检查当前设备、会话成员与实际消息读取权限，admin 不绕过。工作记录、任务、成果、Run、关键词和向量链路继承项目范围；原聊天不导入共享项目表。
- DSH/Hermes 使用同一来源选择器和产品上下文：最近一页中至多 60 条普通消息，输入带作者 UID 和内容版本/摘要引用；成果修订继承旧引用并合并新输入引用。超出 100000 UTF-8 字节在派发前拒绝。成果保存在项目，AI 向 Talk 发消息尚未实现。
- 来源检查在执行期间每 15 秒、模型派发前及每个业务动作/发布前运行；失权后阻止后续写入。浏览器可见页面每 10 秒刷新，失败时关闭私有编辑器并清空相关草稿后切换项目。已发出的数据不能撤回；源编辑/删除的派生成果失效仍待实现。
- 当前本地通过类型、构建、9 单元、34 数据库、12 浏览器、3 原生运行时测试。真实服务 job 新增来源 + 双原生执行器的联合用例（总计 6 项），等待本次 CI。模型仍是本地协议服务，没有真实企业数据或模型效果结论。
- 新增迁移 007；已有来源项目不能直接回退到忽略绑定表的旧版，否则可能扩大资料可见范围。范围、回退保护与未完成项见 [PROJECT-SOURCE-SCOPE.md](PROJECT-SOURCE-SCOPE.md)。冻结交接快照未改。

## 本地环境证据

这台机器缺少 Docker/PostgreSQL，Homebrew 公式元数据与本机 Homebrew 不兼容。因此在被 Git 忽略的 .runtime 中使用官方源包与 SHA-256 校验构建 PostgreSQL 17.11，安装 pgvector 0.8.7，并实际启动本地数据库。没有用 SQLite 或内存数据库代替既定生产存储。

开发库和演示资料仅在本机；配置文件为 .env，不提交。此本地数据库编译方式不是正式部署教程；公开部署以之后提供的 Compose 和经过验证的版本组合为准。
