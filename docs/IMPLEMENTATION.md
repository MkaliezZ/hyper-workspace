- 独立 pg-boss Worker、Run 状态、顺序事件、动作回执、幂等与取消路径。
- DSH 的真实运行时接线与 Hermes 的 stdio JSON-RPC 协议适配；实际验证范围见执行器增量。

- 模型 Key 的服务端加密保存与独立连接验证；DSH/Hermes 使用本次 Run 固定的模型连接。

## 模型与知识模块增量

- ModelService 按当前主体解析个人/工作区配置、用途和优先级；设置页可发起独立连接验证。支持的 HTTP 路径与验证含义见 MODELS-AND-KNOWLEDGE.md。
- 实际 pgvector 索引和语义召回，记录配置/维度/源版本，过滤私有、失效、删除与过期索引；不跨模型空间比较。
- 人工或 AI 修订成果时，同事务更新资料副本并废弃旧向量。
- 模型设置与知识页面拆为独立 React 组件；手机端保持可访问与无横向溢出。
- 本地 7 项单元、10 项数据库集成、4 项浏览器测试通过。向量供应商使用本地确定性 HTTP 测试服务，真实 embedding 质量未验证。

## 执行器接线增量

- DSH 0.2.1-rc.2 已通过真正运行时 + 本地确定性模型服务的双员工并发测试：个人 Key 不串用、目录独立、成果真实保存并回读，秘密未出现在运行文件或产品事件中。
- Run 固定 model_profile_id，Worker 执行时重新鉴权并读取该配置。DSH 使用每次执行的独立 profile，关闭原生 shell/文件/目录工具；产品按 workflow 限制允许的动作。
- AI 修改成果固定起始版本，执行期间有人修改后拒绝覆盖。新增数据库用例覆盖越出工作类型的提案和并发人工修改。
- Hermes 修正为等待 gateway.ready、提交 text、按 session_id 等待 event/message.complete，拒绝错误或部分结果；目前只通过协议 fixture，尚无 Hermes 原生运行时或真实模型证据。
- 通信关闭合并并发请求，等待实际进程退出，关闭后不能重新启动；不再把上游错误正文写入产品错误。
- 当前本地：9 项单元、13 项数据库、4 项浏览器、1 项真实 DSH 运行时测试。运行时测试的模型端仍是明确标记的协议测试服务。
- 成果类工作要求实际业务操作，只有文字回复不能进入 succeeded；执行前先校验整份提案的工具范围。
- 提交 5530395 已通过完整 GitHub Actions（run 40787129677），包括 Ubuntu 上安装固定 DSH 并运行双员工链路测试；模型端仍为协议测试服务。

## 双执行器兼容增量

- Hermes 固定源码提交 780d5a3313d7e1f64c0a0f3ec6b644d50f156e90、源码包 SHA-256 和 Python 3.14.6；通过官方 PM 创建无额外功能包的独立运行环境。
- 两个真正的引擎均通过同工作区双员工并发测试（包含普通成员）：Key、模型、目录、产品可见范围和实际成果回执正确；原生工具关闭，单次输出上限 4096 token。
- DSH → Hermes → DSH 使用同一模型配置和产品成果 ID，版本连续、旧 Run 的引擎不改变。测试模型为本地协议服务，不涉及私有检查点迁移。
- 第一轮往返测试发现修订丢失来源引用，已将人工和 AI 修订统一到同一事务服务，继承来源并更新索引失效状态；复测通过。旧记录若已缺失引用，仍保留缺失状态，不自动推断补造。
- 发起任务可选择模型连接，兼容连接在切换引擎时保持选择；Hermes 不支持的 API 类型在创建 Run 前被拒绝。表单失败时草稿保留，错误显示在有可访问名称的弹窗内。
- 当前本地：9 项单元、14 项数据库、5 项浏览器、3 项原生运行时测试；真实供应商模型、费用、完整 E01–E10 和生产隔离未验收。

## Nextcloud 身份增量

- 独立 IdentityProvider 使用 Login Flow v2、当前用户和自身群组公开 API；后端维护稳定来源 UID/产品 UUID、按设备加密的应用密码及会话，前端只接收授权链接与完成状态。
- 群组准入与产品成员取交集；产品管理员首次映射由受控 UID 配置决定，Nextcloud admin 不自动映射管理员。重新登录不能绕过产品撤权。
- API、模型解析、Worker 开始、业务动作及最终发布前再次鉴权；Run 固定发起设备凭据引用。源服务故障阻止本次操作但不永久删权。产品撤权后旧来源恢复不自动恢复成员。
- 新增 8 项身份数据库测试，本地共 22 项数据库测试通过；2 项登录 UI 协议测试检查重试与移动端取消。两个原生引擎的 3 项测试复测通过，模型仍为协议测试服务。
- 固定官方 Nextcloud 33.0.10 镜像摘要，并新增真实网页登录/应用密码撤销/群组撤销的独立 CI job，首次结果待核验。没有连接真实公司数据。配置、来源绑定、失败窗口和迁移说明见 [NEXTCLOUD-IDENTITY.md](NEXTCLOUD-IDENTITY.md)。

## 本地环境证据

这台机器缺少 Docker/PostgreSQL，Homebrew 公式元数据与本机 Homebrew 不兼容。因此在被 Git 忽略的 .runtime 中使用官方源包与 SHA-256 校验构建 PostgreSQL 17.11，安装 pgvector 0.8.7，并实际启动本地数据库。没有用 SQLite 或内存数据库代替既定生产存储。

开发库和演示资料仅在本机；配置文件为 .env，不提交。此本地数据库编译方式不是正式部署教程；公开部署以之后提供的 Compose 和经过验证的版本组合为准。
