# PDF 与 Office 个人文档接入

P02/P04/P07/P08、C02/C04/C05/C07、A04/A06/A08/A10、E02/E04/E05/E07/E09/E10 子集。固定框架、默认 DSH、兼容 Hermes、资产所有权与来源权限不变；Python 仅为受控文本提取辅助进程，独立于两个执行器。

## 员工流程与范围

“知识库 → 企业文件”显式选择文件并导入个人资料，查看提取文本与限制说明，再选择 AI 阅读或建立语义索引。仍是本人副本，原件在 Nextcloud，不自动发布到共享项目。人工编辑的是个人 AI 解读，未实现 Word/Excel/PPT 原件编辑、富文本或多人协作。

| 格式 | 当前处理 |
| --- | --- |
| TXT/Markdown | 原有有效 UTF-8、64 KiB、18000 字符限制不变 |
| PDF | 可提取文字的最多 50 页，文本包含页码；扫描页明确提示未 OCR，加密 PDF 拒绝 |
| DOCX | 正文段落与嵌套表格按块顺序，表格带行列定位；未确认的插入/删除修订拒绝；不含页眉、页脚、批注、图片 OCR |
| XLSX | 最多 10 张表、每表最多 2000 行/100 列/50000 遍历单元格，准确单元格定位；不读取隐藏工作表；隐藏行列未单独过滤。公式保持表达式并标注未计算，不将缓存值当作当前事实 |
| PPTX | 最多 50 页，组合形状、文字与表格，保留页/形状/单元格定位；不含备注、SmartArt、图表、图片 OCR 或音视频；不承诺形状顺序等于视觉阅读顺序 |

四种二进制文档最多 8 MiB，提取结果含定位最多 18000 字符、2000 文本段；超长内容明确拒绝，不静默截断。宏、加密或损坏包、不匹配的扩展名/MIME、危险或过限 XML/压缩包拒绝。`.doc/.xls/.ppt`、扫描 OCR、长文分块、多文件 RAG 和共享发布仍待完成。

## 产品服务与数据契约

StorageProvider 新增 `extract`，原 `read` 继续返回字符串。Nextcloud Provider 从已验证员工目录取得 fileid/ETag/路径、匹配 MIME 和扩展名，使用 `If-Match` 有界下载，再调用产品解析服务；不接受模型提供的下载 URL 或可执行文件。

`DocumentExtractor` 通过 argv 启动固定 Python/脚本，无 shell。环境仅包含必要的 Python 开关，不继承产品凭据、数据库、HOME 或源密码；文件走 stdin，不写临时文档。每个 API 进程最多同时 2 个解析进程，繁忙返回明确 503；20 秒墙钟超时、512 KiB stdout、16 KiB stderr 限额，取消或超限终止后等待 close 才释放容量。诊断只计字节，不缓存或记录，返回结果按严格 schema、格式和文本/段落一致性检查。取消接口目前是服务内部 AbortSignal，尚未连接浏览器请求断开或导入取消按钮。

辅助进程另有 15 秒 CPU 限制与 Linux 1 GiB 地址空间上限；所有 OOXML 部件先有界解压校验。不解析二进制打印设置或嵌入代码。PDF 解压大小判断本身需要解码，仍须进程限额；该措施不等于独立容器/完整操作系统沙箱。原生模型/Worker 不拥有解析器资产目录。

导入完成后重新核验产品、设备、来源下载权限及精确 id/ETag/size/MIME。读取期间变化拒绝保存。`cw_source_files.parser_version` 与 `extraction_metadata` 保存格式、定位段落和限制说明；源副本版本包含 ETag、文件名、文本摘要、解析器版本与元数据摘要。原纯文本的版本计算保留兼容。

解析器版本升级时必须同步修改 Python/TypeScript 版本常量。读取、索引和 AI 派发核验时发现解析版本不同，清空旧正文/向量/解析元数据和关联个人解读/Run 输入结果，要求员工显式刷新。源变更、删除和撤权沿用相同失效路径；检测发生在读取/检索/索引等入口，未实现全量实时撤权推送。元数据不作为独立可公开资产。

AI 上下文使用带定位的提取文本、解析版本/格式和限制说明，不重复注入完整段落数组；仍受 100000 UTF-8 字节上限约束。业务工具入口和保存回执沿用个人阅读/续改，不因 DSH/Hermes 切换而改变文件、来源版本或可见范围。

## 依赖、部署与迁移

[解析组件](../runtime/documents/README.md) 锁定全部 Python 直接及传递依赖版本/发行包哈希；CLI 和 TypeScript 调用器都归产品维护。开发前安装该独立环境：

```bash
python3 -m venv .runtime/documents
.runtime/documents/bin/python -m pip install --require-hashes -r runtime/documents/requirements.lock --index-url https://pypi.org/simple
```

Docker 构建使用既有 Python 镜像，创建独立提取环境并按哈希安装，将环境与脚本放入受限只读应用镜像。不在运行中下载，不复用 Hermes 虚拟环境。Linux/amd64 的实际构建、四种格式与源码来源链路以本轮 CI 为准，本机无 Docker；ARM/Windows 和公司文件未验收。

新增迁移 `015_document_extraction.sql`，只加默认空对象的提取元数据列及对象类型约束，不推断旧文档定位。升级前备份、停止新工作与旧 Worker，管理员迁移后共同升级 API/Worker/Web；运行角色仍不持有迁移权限。混跑旧版会忽略解析版本或限制说明，不能作为安全回退。回退前停止写入，核对活跃 Run，保留源版本/提取元数据/阅读历史和备份，优先向前修复；备份恢复/正式回退尚未演练。
